### From L-39: Charitable Giving and Financial Planning

**Day 1 Skill Builder**:
- **Title**: Personal Charitable Giving Plan
- **Steps**:
  1. Choose a cause/organization you're passionate about
  2. Determine contribution type (monetary, time, in-kind, or combination)
  3. Set specific, realistic goals
  4. Write strategy paragraph explaining why, how, and impact

### From L-40: Checking Out Charitable Groups

**Day 1 Skill Builder**:
- **Title**: Researching Charitable Organizations
- **Steps**:
  1. Choose a charitable organization
  2. Use evaluation tools (Charity Navigator, GuideStar)
  3. Gather information on mission, finances, impact
  4. Answer evaluation questions and decide if you'd support

**PACED Model Application**:
- Problem: Define cause to support
- Alternatives: Identify organizations addressing that cause
- Criteria: Establish what matters (effectiveness, financial health, local impact)
- Evaluate: Compare each org against criteria
- Decide: Choose best alignment with priorities
